# The menu

Click the half-filled circle in the menu bar.

| Item | What it does |
|---|---|
| The first two lines | The version, and what is showing now, for example *Aurora in Aurora*. |
| **Shuffle** | A new picture now. A random style or tonality changes; a locked one stays. See [Shuffling](../pictures/shuffling.md). |
| **Style** | **Random**, or one of the [eleven styles](../pictures/styles.md) to keep. |
| **Tonality** | **Random**, or one of the [eight tonalities](../pictures/tonalities.md) to keep. |
| **Spaces** | [A picture per space](../desktop/spaces.md), or the same one everywhere. |
| **Shuffle Automatically** | Never, every hour, every 3 hours or every day, and on login and wake. |
| **Grain** | None, subtle or strong. The settings window has a slider. |
| **Hide the Notch** | A black menu bar strip the notch disappears into. See [Notch and corners](../desktop/notch-and-corners.md). |
| **Round Corners** | Black outside rounded corners, so a window tiled into a corner meets black. |
| **Show Title** | A centred [title and subtitle](../desktop/grain-and-title.md). |
| **Settings…** | Everything above, plus the title's text, the corner radius and the grain's strength. |
| **Pause** | Leave the desktop alone: nothing is set or put back until you turn it off. |
| **Open at Login** | Start with your Mac. It is a normal login item, listed in System Settings › General › Login Items. |
| **Check for Updates…** | Look for a new version now. See [Updates](../reference/updates.md). |

![The settings window](../images/shots/app/settings-dark.png)

Every change applies straight away: the picture is drawn again (in a second or so) and set.
