# Getting started

Undertone runs in the menu bar, has no Dock icon, and needs no permissions: setting the desktop picture is something
any app may do.

- [Installation](installation.md): Homebrew, the install script, or a download.
- [The menu and settings](the-menu.md): quick toggles in the menu bar, everything else in Settings, with previews.
